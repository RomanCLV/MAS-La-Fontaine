# Module print (`src/js/print/feuilles.js`, `Recueil.Feuilles` + `src/css/feuilles.css`)

- `Feuilles.cuisine(donnees, semaine, creneau)` → élément `.feuille` (A4 paysage, 1123 × 794 px = 297 × 210 mm) reproduisant la maquette `Main` v2.1 : en-tête + TOTAL À PRODUIRE, pastilles « Sur ces N plats », tableau zones PARCS (+ activités, en-tête à la couleur de l'activité, + total parcs) / SODEXO / DIRECTION / AUTRES / TÉMOINS / TOTAL, sections REPAS (dont ligne « + Plats en plus (options) » en gras = options « +1 plat chaud (EQ +1) », et ligne « Plats témoins »), TEXTURES, RÉGIMES, OPTIONS (lignes issues du référentiel, chaque texture — Normal compris — en grand et colorée).
- `Feuilles.chariots(donnees, semaine, creneau)` → une ou plusieurs `.feuille` par parc et par activité ayant un volume > 0 (maquette `ChariotA`) : en-tête coloré, collectif (bacs **Salariés standard / Salariés sans porc** sur fond beige, **Résidents simples / Résidents sans porc** sur fond bleu, petit bandeau SALARIÉS / RÉSIDENTS ; un bac n'est imprimé que si sa quantité n'est pas 0), étiquettes 6 par page (page suivante si besoin) ; sur un chariot d'activité, l'en-tête de l'étiquette rappelle le parc (« PARC <nom> », couleur du parc).
- `Feuilles.construire(donnees, semaine, {cuisine, chariot, jours, servicesExclus})` → fragment avec toutes les feuilles dans l'ordre jour × service (`Modele.creneaux(semaine)` : un service additionnel seulement ses jours servis cette semaine).
- Impression : `#impression` (hors de l'application) reçoit les feuilles puis `window.print()`. CSS : `@page { size: A4 landscape; margin: 0 }`, saut de page entre feuilles, couleurs forcées (`print-color-adjust: exact`).
- Ajustement à la page : le tableau prend la place restante (`container-type: size`) ; `--n` = nombre de lignes (total/textures 1,4, bandeau 0,9) ; hauteur et texte des lignes réduits proportionnellement s'ils ne tiennent pas (sinon 20 px / 14 px comme la maquette).
- Repas sans porc (`menuSansPorc`) : feuille cuisine = « Menu sans porc » dans le sous-titre, une ligne « Salariés » au lieu de standard / sans porc (la ligne « Sans porc » tombe d'elle-même à 0) ; chariot = bandeau « COLLECTIF · bacs à charger · menu sans porc », bacs « Salariés » et « Résidents simples » seulement, pas de phrase de pied sur les sans porc ; étiquettes inchangées.
- Lignes textures / régimes / options : seulement celles qui concernent le service **et dont le total n'est pas 0** (idem pour les pastilles « Sur ces N plats », masquées si aucune) ; groupe vide non affiché.
- Service « présence seulement » (petit déjeuner, ou service additionnel de ce type) : section REPAS (sans plats en plus ni pastilles « Sur ces N plats ») + éléments cochés pour ce service, total en « petits déj. » (autre service : « convives ») ; feuille chariot simple (`chariotSimple`) : bacs Salariés et Résidents (mêmes couleurs, masqués à 0), encadré « Particularités » (élément, nombre, noms), pas d'étiquettes.
- Aucune alerte, aucun texte « manager » sur les feuilles.
- Pots gourmands : petit déjeuner seulement (par défaut) ; ligne OPTIONS de la feuille cuisine et encadré Particularités du chariot.
