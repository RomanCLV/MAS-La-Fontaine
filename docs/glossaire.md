# Glossaire métier

| Terme | Définition |
|---|---|
| Parc | Zone/unité de l'EHPAD (Amboise, Bonaguil, Collioure, Lude, Mirande, Sully, Alhambra). 1 parc = 1 chariot. |
| MAS | Maison d'Accueil Spécialisée (La Fontaine) — l'établissement client. |
| SOL | Logiciel Sodexo dont est extrait le menu (`menu 26.xls`). |
| Client | La MAS, qui saisit les effectifs hebdomadaires. |
| Prestataire / nous | L'équipe de restauration (l'utilisateur) qui reçoit l'effectif et prépare. |
| Chef | Cuisinier qui lit la feuille de production. |
| Feuille cuisine | Feuille de production A4 paysage (par jour et service) lue en cuisine. Anciennement « feuille chef ». |
| Convive | Résident ou salarié qui mange. |
| Régime | Contrainte alimentaire impérative (sans porc, diabétique…). |
| Texture | Haché, mixé. |
| Option | Ajout/substitution (double légumes, double plat, pots gourmands, enrichi…). |
| Sport | Bloc temporaire du jeudi midi, regroupe des résidents de plusieurs parcs, chariot distinct. |
| MCH | Nom de la feuille de saisie client ("Effectif MCH"). |
| MATFER | Nom de la feuille de récap chariots (matériel de transport). |
| Pots gourmands | Alternative au petit déjeuner classique pour qui ne peut pas mâcher (yaourt, riz au lait, crème pâtissière + brioche…). Préparée par la cuisine, à la place du petit déjeuner (pas en plus). |
| Sans résidus | Régime pauvre en fibres. |
| Enrichi | Plat enrichi en calories/protéines. |

- **Activité** : évènement ajouté à une semaine (ex. Sport jeudi midi) dont les participants mangent ailleurs ; ne change pas la portion, change le chariot.
- **Service** : moment de repas d'une journée. **Services de base** : petit déjeuner, midi, soir (fixes). **Service additionnel** : ajouté par l'utilisateur (goûter, collation, repas de fête…), certains jours seulement si besoin, type « Repas » ou « Présence seule ».
- **Preset (activité)** : modèle enregistré (jour, service, participants) réutilisable d'une semaine à l'autre.
- **Équipe Sodexo** : cuisiniers du prestataire, ajoutés au volume total, hors parcs.
